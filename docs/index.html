Physical Computer Project

About The Project

ระบบนับเวลาแบบ Pomodoro ที่เชื่อมต่อฮาร์ดแวร์เข้ากับหน้าเว็บแบบ Real-time

Arduino Uno R4 WiFi

Physical Controller

รับคำสั่งจากปุ่มกดจริง (Start/Pause/Reset) ควบคุมรอบเวลา แจ้งเตือนผ่าน LED/Buzzer และส่งสถานะผ่าน Wi-Fi

Web Server

Backend & API

รับข้อมูลจาก Arduino เพื่อจัดการสถานะ และส่งข้อมูลแบบ Real-time ผ่าน WebSocket

Pomodoro Dashboard

Frontend Interface

หน้าเว็บแสดงเวลาที่เหลือ โหมด Focus / Break ความคืบหน้า และประวัติการทำงาน

Component

อุปกรณ์ฮาร์ดแวร์ที่ทางกลุ่มเราได้เลือกใช้ในโปรเจคนี้

LED

สำหรับแสดงผลสถานะการทำงาน

Buzzer

ส่งเสียงแจ้งเตือนเมื่อตรวจจับว่าผู้ใช้กำลังใช้โทรศัพท์หรือไม่อยู่โต๊ะทำงานขณะที่อยู่ช่วง Focus หรือเมื่อหมดเวลา

Button

ปุ่มกดสำหรับสั่งงาน Start, Pause และ Reset รอบเวลา Pomodoro

Potentiometer

สามารถเลื่อนหรือหมุนได้เพื่อให้ผู้ใช้สามารถปรับเพิ่มลดระยะเวลาได้ผ่านอุปกรณ์นี้
